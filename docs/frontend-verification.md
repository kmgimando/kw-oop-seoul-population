# 프론트엔드 검증 결과

검증일: 2026-10-30. 로컬 feature/seasonal-frontend 브랜치에서 수행했다. commit, push, PR은 생성하지 않았다. 기존 seasonal_analyzer.py와 Python 테스트 및 다른 팀원 담당 파일을 수정하지 않았다.

## 자동 테스트

| 명령 | 결과 |
| --- | --- |
| python -m unittest discover -v | 36개 통과, 실패 0 |
| node --test tests/frontend/dashboard.test.mjs | 19개 통과, 실패 0 |

실행 환경: Python 3.13.15, Node 24.22.1. JS 테스트에 외부 패키지는 필요 없다. static/js/package.json은 Node 테스트에서도 브라우저 ES module을 읽기 위한 type 선언만 포함한다. npm 설치나 프론트 빌드 과정은 없다.

JS 테스트는 25개 자치구와 세 방법, 날짜/설정 검증, 비율/Z-score 단위, 판정 가능 분모, 0 기준값/표준편차, null 보존, 차트 데이터, 설정 변경, 빈 결과/오류, 응답 계약 검증을 포함한다. 요청 중단을 무시하는 가짜 transport를 사용해 오래된 성공/실패가 최신 결과를 덮어쓰지 않는 것도 검증했다.

## 실제 브라우저 확인

Codex 인앱 Chromium 브라우저에서 정적 HTTP 미리보기를 열어 다음을 확인했다. 브라우저 조작으로 확인한 항목이며 별도 브라우저 테스트 프레임워크는 추가하지 않았다.

| 항목 | 결과 |
| --- | --- |
| 마포구 → 강남구, 계절성 → Z-score → 이동평균 변경 | 적용 조건과 결과 갱신 |
| Z-score/비율 임계값, 계절성 최소 표본 표시 | 단위·표시/숨김 확인 |
| 역전 기간, 임계값 0, min_samples > window | 오류 표시, 이전 결과 숨김 |
| 실제값/기준값/상하한/이상점/판정불가 배경 | 차트 렌더링 확인 |
| 차트 클릭과 툴팁 | 날짜·상태·수치 표시 및 상세 연동 |
| 날짜 버튼과 이상/판정불가 필터 | 상세와 결과표 갱신 |
| 빈 결과와 오류 시나리오 | 메시지 표시, 이전 결과 숨김 |
| 기준값 0 / 표준편차 0 | 정상 상태와 null 점수를 정확히 표시 |
| 판정 가능한 날짜가 없는 기간 | 탐지율 —, 판정 가능 0일 |
| 느린 요청 직후 새 자치구/일반 요청 | 로딩 표시 및 최신 조건 결과 유지 |
| 모바일 390×844 크기 | 조회 동작, 차트 표시, 페이지 가로 넘침 없음 |
| 최종 브라우저 콘솔 | 오류·경고 없음 |

모바일의 넓은 표는 표 영역 안에서 좌우로 스크롤한다. 모바일 검증 중 발견한 차트의 최소 너비 문제를 수정하고 전체 페이지 가로 넘침이 없음을 재확인했다. 모바일 viewport override는 검증 후 해제했다.
